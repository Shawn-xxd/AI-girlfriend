# 角色字段与首条招呼语

2026-11-26 用户确认六个内容字段：名字、定位（Role）、标签、角色宣言（Discover）、长人设、首条消息招呼语。保持现有字段与内容：name、archetype、tags、bio、system_prompt；仅新增 first_message。bio 复用于人物简介页。长人设包含性格、背景、Scenario，只通过后台编辑并供模型使用，不在公开角色接口中返回。

模型输入使用姓名、Role、长人设，公开宣言不作为额外人设规则。沿用既有生成、审核和记忆流程，不增加聊天节奏等新约束。

新会话在创建事务中把角色 first_message 去掉首尾空白后保存为 greeting_message；复用已有 user/character 唯一会话时不会修改。空内容不生成招呼语。已有会话不回填；修改角色招呼语只影响以后新建的会话。首次招呼语作为会话元数据持久化，由公开 conversation/detail/list 的可选 greetingMessage 字段返回，避免把它伪装成用户/AI 的已完成回合或改变旧 timeline 契约。

移动端在最早一页历史前显示招呼语。分页尚未加载到最早记录时不把旧招呼语插在近期消息中；稳定行 ID 和会话缓存用于重复进入及冷启动恢复。模型收到相同的原始招呼语作为对话背景。招呼语不创建 chat_turn、messages、AI 用量或计数凭据，不增加等级；正常一来一回仍按既有事务计一次。
