# Me 与付费页（2026-11-19）

本轮是移动端页面与现有功能接入。Me 展示匿名用户的真实钱包余额；姓名、称呼沿用本机引导资料，通过独立 updateProfile 操作在引导完成后编辑、保存并恢复。不得更改完成状态、年龄/条款同意、偏好或匿名身份；读写错误不显示保存成功。资料尚不上传给聊天模型，也没有新增语言切换、账号登录或跨设备资料恢复。

付费页统一接入 Me、Discover、聊天与相册的会员/钻石入口。用户确认方案：月 USD 12.99、年 USD 49.99；年方案月均按四舍五入显示 USD 4.17，节省约 68%。权益为不限量聊天、Private photos 入口、首次一次性 150 钻、Premium 角色、2 倍钻石奖励及专属优惠。用户明确会员私照仍扣钻，不能文案承诺免费解锁全部私照，150 钻不能随续费反复发放。权益仅是已确认待接入方案，本轮没有启用订阅、发钻、扩权或修改现有额度。

用户确认 App Store Connect 应用、月/年订阅商品、RevenueCat 项目尚未创建，因此付款按钮明确不可用；恢复购买不模拟成功。钻石包价格/数量尚未确定，不编造充值商品。当前只有本地选择计划，不接受客户自报金额、订单、钻石余额或会员标记。真实上线时商品本地化价格与订阅周期必须来自 Apple/RevenueCat offering，当前 USD 为已确认方案展示。

帮助/反馈、隐私和条款通过现有公开配置 EXPO_PUBLIC_SUPPORT_URL、EXPO_PUBLIC_PRIVACY_URL、EXPO_PUBLIC_TERMS_URL 打开 HTTPS 页面。缺少时说明尚不可用，不生成冒充正式法律文件的内容。配置值及正式内容仍待用户准备。

后续支付接入需要：创建 App Store Connect 应用与同订阅组中的月/年商品；创建并关联 RevenueCat；安全环境变量提供服务端密钥/webhook 鉴权，公开 SDK key 可进入移动端；新增验单订单、一次性赠钻去重、权益校验与退款事件处理；确定 2 倍奖励的基础奖励来源；单独确认匿名身份下跨设备恢复和钻石归属。真实商品以 com.tempta.ai 对应应用为准，不能把当前 com.tempta.ai.preview 的 ad hoc 包视为已可购买。新增原生 SDK 后需按新 fingerprint 重新构建签名包，并在沙盒/TestFlight 验证购买、恢复、续费、退款和重复事件。不会重建现有 Supabase 或 Railway 服务；支付接入可能需要新增数据库迁移及后端接口，本轮均未改动。

验收范围：pnpm check、移动端 iOS 导出和兼容 runtime 的 OTA 发布；真机视觉、键盘、资料保存以及页面导航由更新后的设备验证。不能将页面发布写成真实支付已完成。
