# Discover 视觉基准

2026-11-04 用户提供 IMG_7907.PNG，要求参考该 UI 修改首版。以 393×852 作为浏览器验收基准，保持页面干净，开发人像后续可替换。

- 人物图从屏幕上缘铺满到 Tab 上沿，去掉页标题、内缩卡片和外框圆角。底部黑色遮罩只保证信息可读。
- 右上黑底红边钻石胶囊（高 32pt），右下 14pt 加号；相邻 32pt 黄色圆形皇冠。用户要求缩小视觉尺寸，入口仍保留至少 44pt 触控高度，安全区下方显示。未知余额为 —，不复制参考的 87。
- 下方姓名为约 33pt 白色粗体，右侧红色大写类型徽章；简介约 15/20pt，最多三行；三个浅色 hashtag。
- 白色圆形 X 约 88pt，红色圆形 Heart 约 92pt，二者横向分布；小屏缩到 74pt。
- 灰色底栏和方形图标底，高亮为红底白图标；保留 Discover、Chats、Me 三个入口和简短标签。
- 点姓名行打开详情，继续支持左滑/X 跳过与右滑/Heart 选择。预览仍只展示资料，正式模式创建会话。
- 简短 AI/Preview 标识位于左上；不添加未实现的余额、在线状态、付费锁或礼物入口。

文字/按钮结构与参考对齐；人物素材、字体和跨平台 Emoji 不声称逐像素一致。iOS 原生安全区效果须真机验收。
