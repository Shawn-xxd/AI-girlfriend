# 匹配与 Gallery 视觉基准

以用户 2026-11-08 两张图为参考；基准画布 393×852，小屏可滚动。人物和字体仍为开发素材/Arial 近似。

匹配页：人物铺满、左上 58pt 白色圆形返回和粉红箭头；下方居中 ITS A（约 58pt 白色粗体）、MATCH（约 60pt 粉红斜体）；底部红色 CHAT NOW 高 64pt、圆角 13pt、左右 8pt，保留安全区。不添加介绍或促销段落。

相册：深灰背景，顶部沿用聊天头像/姓名/红色类型胶囊、已缩小的钻石入口和圆形聊天图标。两枚页签约 48pt，高亮 All photos 有红色描边/下划线，PRIVATE 为橙色并带锁。两列照片按约 0.72 宽高比铺排、间隔 12pt；锁定图为模糊棕色遮罩，白色标题，下方红色 OPEN / 白色价格块或黑色等级按钮。底部按图保留返回聊天横幅。没有虚构在线状态或真实余额。

Level 1 / Level 2 / 7 Diamonds 只用于显式设计预览；正式 API 配置与授权未接入时不显示这些示例。
