# Onboarding 视觉基准

用户确认以三张原尺寸参考图（目标、兴趣、角色介绍）及最初 12 屏流程图为准，不重新设计另一套风格。页面保持干净，不添加眉题、宣传语、进度条、标签或额外装饰。

- 基准画布 393×852；人物图铺满、底部暗色遮罩，内容居中。
- 内容左右约 17；底部主按钮高约 62、圆角约 12、粗体字约 18，常规底部留白约 54；小屏允许纵向滚动。
- 返回为左上白色圆按钮、粉红箭头，位置和出现页面依参考流程。
- 介绍页只保留白色粗标题、一句灰色说明和红色 Continue；隐私文案保持真实，不编造保密保证。
- 输入页保留名字、代词及下一步；偏好页的大选项与其他表单页一致，选中为黑底白边。
- 兴趣按 3/3/3/2 排列，目标按 2×2 排列；保留真实多选与草稿恢复，不把参考图中的示例选择设置成默认答案。
- 欢迎页保留必要成年确认及条款入口；AI 身份在欢迎文案中披露，不在每页重复介绍。
- 照片介绍保留金色卡片、短文案、可跳过的订阅入口及必要条款；不编造未确定价格，也不授予订阅权益。

字体目前以 Arial 近似匹配；不同系统 Emoji 与参考图不同。人物仍为开发素材，不能声称截图内容或字体已像素级一致。iOS 真机安全区、键盘和系统字体尚须实际验证。

本轮 `pnpm check`、web 导出及静态产物的完整浏览器流程通过。预览与新版体验包保存在 /workspace/scratch/onboarding-unified-preview 和 /workspace/scratch/Flirtly-Onboarding-Preview-V2.zip；体验包是本机浏览器预览，不包含真实聊天或支付。
