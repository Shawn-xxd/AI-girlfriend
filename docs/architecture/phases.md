## Phase 2 任务顺序

1. 确认 Supabase 开发项目、匿名会话开关与公开 publishable 配置、DeepSeek 服务端配置；建立独立开发凭证。
2. Supabase access token 验证、User 幂等映射、资源归属测试；游客会话先在真实设备开发构建验证，不加入登录页。
3. Character 发布状态与可见字段、最小开发种子数据；无正式素材时使用明确的开发占位内容。
4. Conversation/Message 迁移、历史分页、发送幂等键和失败状态。
5. 可替换模型适配器（当前 DeepSeek）：超时、错误分类、输入输出限制、用量；真实 API smoke 验证，测试替身仅用于自动化异常测试。
6. 按参考完成首次引导与免登录使用，再完成角色聊天闭环；进行流式传输可行性验证，完整断线/等级行为留在 Phase 3。

生产角色、价格与支付功能不属于 Phase 2。外部凭证缺失时明确报告未验证，不能用 Mock 的成功代替真实闭环。
