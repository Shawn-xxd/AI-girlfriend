# ADR 0005：Phase 2 会话与真实 AI 回复

状态：用户授权继续开发；未扩展到 Phase 3 等级/照片/完整流式行为。

会话按用户和角色唯一隔离。数据库函数验证 actor/角色发布状态并创建会话，消息发送使用客户端 UUID 幂等键。一次会话只允许一个有效生成租约；过期可恢复，generation UUID 防止旧请求覆盖新结果。用户消息与请求状态在同一事务创建，完成时原子保存助手消息、模型响应 ID 和 Token 用量。失败有持久状态，相同内容与幂等键可重试，换内容复用键返回冲突。

外部 OpenAI 调用不放进数据库事务。网络响应丢失时可通过同键重试读取已完成消息；外部生成在崩溃/租约过期场景不保证计费严格一次，不伪造“恰好一次”承诺。模型与输出上限由服务端配置，暂不制定最终免费/订阅额度或价格。

使用 OpenAI 官方 SDK 的 Responses API，真实输入/输出审核，拒绝露骨互动与未成年性内容，系统提示明确 AI 身份与成年非露骨边界。角色 Prompt 与业务操作分离，模型不能修改余额、等级或图片权限。Phase 2 使用近期成功轮次，摘要和断线流式恢复在 Phase 3 实现。

角色下架后历史可读，暂不允许新增会话或继续生成，避免未审核内容继续服务；后续如有运营需求再明确调整。非本用户资源统一返回 404。服务端凭证只在 API，普通客户端无表/RPC直接权限。

凭证缺失时返回 503，不返回模拟回复。真实 OpenAI 验证需要安全配置 API Key、模型及网络域名；缺少时继续完成代码和数据库/异常测试，最终明确标为未验收。移动端 Apple 登录及真实设备仍须单独配置/验收。
