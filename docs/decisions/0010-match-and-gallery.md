# ADR 0010：匹配过渡与独立相册页

2026-11-08 用户要求 Discover 点 Heart 先显示参考图的全屏 ITS A MATCH，再点 CHAT NOW 聊天；聊天相册入口显示完整双列 Gallery。

匹配页只负责展示当前虚构 AI 角色，不增加真人匹配算法或喜欢流水。Heart/右滑只导航；CHAT NOW 才创建/取得真实会话（Preview 才创建本地设计会话），不自动发消息或调用模型。返回匹配前不产生会话；进入聊天替换匹配路由，避免返回栈积累。

Gallery 是独立受保护路由，按当前会话从服务端获取角色资料，不信任路由中的姓名/头像。顶部与聊天共用角色栏，右侧聊天图标/返回键回到同一会话。打开 Gallery 不重新刷新已就绪 viewer，避免卸载后台聊天、清空未发送输入；深链首次进入仍需真实身份和归属检查。

参考图的 All photos 是全部照片视图，PRIVATE 是 Diamond Photos 的视图快捷入口，底层仍只有 Level / Diamond 两种照片，不新增 Free / Premium 分类。预览样例可展示 Level 2 和 7 Diamonds 的排版，这些数字只存在显式 Preview fixtures，不能作为正式阈值或价格。正式照片 API、等级和 Wallet 尚未接入，本轮正式 Gallery 显示真实空态，不从前端发放权限或扣款。锁定预览点击只说明条件，不解除模糊或改变余额。

用户提供的截图仅作布局参考，不当作无字背景；继续使用既有虚构成人开发素材。展示 Preview 标记，不编造在线状态、真实余额或图库数量。代码不改变数据库、AI 审核或支付规则。
