# ADR 0003：切换 Mac 本地开发

状态：用户批准。

Codex 当前云环境的 DNS/数据库网络限制尚未解决；停止将其作为当前关键开发阻塞。在 Mac 运行移动端和 API，继续使用 Supabase 开发数据库，保持原技术栈。通过 Git/GitHub 管理代码，后续由 Railway 部署 NestJS；EAS 发布移动端。

本地采用用户已安装的 Node 24.22.2，更新 .node-version；当前云机器仍是 Node 24.19，不能据云端测试声称已验证所有 Mac 原生依赖。pnpm 保持 11.25.0，使用 npx 调用以避免全局安装权限问题。

官方数据库 CA 与密码保存在被忽略的本地目录和 .env，不提交 Git。服务端运行与迁移连接均配置 CA 和主机名验证。云端部署时重新注入凭证与证书，不复制 Mac 的绝对路径。

不再要求用户为该云环境配置 Tailscale，也不再以云任务直连 Supabase 作为本地开发前置步骤。当前选择不等于原网络问题已修复。
