# ADR 0008：Discover 与真实会话入口

2026-11-03 用户要求继续开发 Discover。沿用已确认的干净、深色、人物大图风格，先完成单角色卡片、名称/类型/简介/标签、左滑/X 跳过、右滑/Heart 选择、Diamonds/Premium 入口及三个 Tab。不加入匹配算法、关系值、永久喜欢记录或新商业规则。

正式模式使用现有 NestJS `/v1/me`、`/v1/characters` 与 Conversation API，调用前取得真实游客 token；严格校验响应、限时请求、脱敏错误，按业务用户隔离缓存。开始聊天仅创建/取得幂等会话，不自动生成消息或重复发起付费请求。提供最小消息历史/发送界面承接入口；完整流式和高级聊天体验留待对应阶段。

当前公开 publishable key 缺失，匿名开关须以当前只读检查为准。正式模式不得静默使用演示角色或伪造会话/消息。`EXPO_PUBLIC_DISCOVER_PREVIEW=1` 仅供开发体验包显式展示六位虚构成年角色与本地开发图片，页面标识 Preview，停止游客初始化；预览不会创建真实会话、请求 AI 或授予权益。

角色正式 DTO 暂无封面字段；正式模式没有已配置封面时显示中性图片占位，不随机把开发人像分配给真实角色。开发图片仅属于显式预览数据；私有角色封面的存储/签发与运营配置后续另行接入，不把 Gallery 权限实现为客户端开关。

Wallet/RevenueCat 尚未实现，余额显示未知状态，不虚构 0 或赠钻；点击 Diamonds/Premium 可查看对应说明/当前不可购买提示，不扣款、不发放订阅。X 只影响本次浏览队列，浏览完可重新浏览；不把 Heart 称为已匹配真实人类。

浏览器预览支持本地 API 的明确 origin 白名单 CORS，原生 App 不依赖 CORS；不使用通配 origin 携带凭证，不把 server key 发送给客户端。验证包括队列边界、手势意图、API 响应/错误、重复点击、真实/预览隔离与完整移动视口操作。真实游客/API 联调和 iPhone 真机结果单独报告。

2026-11-04 视觉调整按用户提供的 Discover 原图执行：人物全屏铺到 Tab 上沿、右上悬浮钻石和金色皇冠、下方名称与红色类型徽章、简介、浅色 hashtag、大号白底红 X 和红底白 Heart。取消页面标题与卡片边框；底栏采用灰色块状图标，继续只保留 Discover / Chats / Me。点击名称行查看完整资料。AI/Preview 标识保持简短；不复制参考图中的虚构余额、真人在线状态或未定义的付费聊天锁。此次不改变接口、钱包和聊天规则。

聊天阶段按 ADR 0009 更新：显式预览的 Heart 现在打开设计聊天页，可本地输入和查看开发照片；不会生成假 AI 回复或发放权益。正式模式的会话入口、权限和付款规则不变。

2026-11-08 流程更新见 ADR 0010：Heart 先进入独立 Match，再点 CHAT NOW 创建会话；聊天相册入口改为独立双列 Gallery。旧版弹层/直接进入聊天描述保留为开发历史，以 match-gallery.md 为最新验收。
