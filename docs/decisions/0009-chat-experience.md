# ADR 0009：聊天界面与审核后的流式交付

2026-11-04 用户确认继续开发 Chats / 聊天详情，提供人物全屏背景、头像/类型、深色白描边气泡、底部胶囊输入框的参考图。保留免登录流程及服务端授权，优先实现现有接口闭环，不增加角色扮演模式、定价、赠钻或图片权限规则。

## 界面与数据

正式聊天页从受保护的 conversation detail 接口获取角色公开资料，不以路由参数作为角色身份来源；没有正式照片配置则显示中性背景和头像。会话列表由服务端提供公开角色及最后一条消息，批量关联查询，不把 system_prompt 或凭证传给客户端。支持早期分页、发送与失败重试、按消息键保存待发送草稿、返回列表及历史回看。

显式 EXPO_PUBLIC_DISCOVER_PREVIEW=1 下，Heart 可进入明确标识 AI / Preview 的聊天设计页，展示既有虚构成人角色、固定示例问候及一张照片卡片。发送只追加本地预览消息，不生成假 AI 回复、不请求服务器、不授予照片/等级权益；预览图库打开的仅是同包开发图片。正式模式不使用这些默认问候或照片。参考图的 ROLEPLAY 卡片改为 PHOTO，避免引入未经确定的功能。正式余额未知、照片计数/等级未接入时不伪造数值。

## 流式与审核边界

保留现有输入/输出完整内容检查和持久化事务。新增 POST messages/stream，使用带 bearer token 的 fetch SSE，不把凭证放 URL，也不使用自动重连重复付费。DeepSeek / 兼容 Chat Completions 和 OpenAI Responses 可读取真实上游流，服务器只缓存有界文本，不转发 reasoning_content 或未审核的 delta。客户端实时收到 checking / generating / saving 状态；完整输出审核并成功保存之后，才收到 completed 消息。此版本没有逐字提前展示；不用客户端打字动画冒充模型流。

客户端断开只停止网络交付，已开始的一轮继续在有界模型超时/数据库租约内审核并保存，以便回到历史恢复；不自动重新生成。手动重试同内容复用 requestKey，已完成轮次重放原结果。页面卸载或身份更换取消客户端流；回到页面按历史状态恢复，跨重启保存的待发送键按真实游客和会话隔离。安全错误码和事件大小均受限，未知/截断流失败，不回退再次付费调用。

这不等于完成全部 Phase 3：摘要、计数、等级、私有图片、支付和分段审核仍按后续阶段实施。公开 key / 平台匿名开关缺失时报告真实联调阻塞，明确区分 HTTP 测试替身与真实供应商验证。
