# ADR 0012：有效聊天、永久等级与等级照片

2026-11-08 用户确认：用户消息与 AI 回复审核通过且成功持久化后计一次；失败、拒绝、同键重试不多计；事务完成后断网仍计一次。已获得等级与图片权限不因门槛调整或消息删除回退。

- 使用现有回复完成事务上的数据库触发器记录唯一 turn 计数事件、更新 UserCharacterProgress、计算单角色可配置等级、永久授予 PhotoUnlock 并插入照片消息。任意一步失败则回复保存一起回滚；不在移动端或独立 HTTP 调用间拼接事务。
- 计数事件、进度和解锁不依赖聊天消息外键；用户删除才清理个人进度。删除消息、回合或会话不撤销已获权益。一个用户/角色只有一份进度，一个用户/照片只有一次授权和一次奖励发送。
- Level 1 从 0 次开始。更高门槛无正式默认值，按角色通过受限服务端配置 RPC 原子替换并校验递增；提高门槛不降级，降低门槛在下次打开聊天或成功回复时重新计算。历史成功回合在迁移中一次回填，不重算被删消息。
- 照片先由运营预制并审核/发布；本阶段只发放 Level Photos。没有已审核发布素材时不以本地素材冒充真实奖励，不新增价格、钱包或 Diamond 解锁逻辑。
- 照片消息使用独立表及同一会话 sequence，与现有文字消息合并分页。原有 /messages 与回复 SSE 契约保留；新 /timeline 返回文字、照片和服务端进度，避免破坏幂等重放。
- 图片位于 Supabase 私有桶 companion-photos。访问接口重新验证匿名 JWT、会话归属、照片归属/审核状态、永久授权和桶的 private 属性，只签发短时 URL；不向未授权客户端返回 object key 或原图。已获照片下架仍可访问；审核撤回则暂不提供图片，但保留权限记录。
- 手机端点击 OPEN 后在原卡片显示获授权图片，保留布局和草稿。照片授权不随签名 URL 过期而失去；失效时重新获取，界面不添加额外流程说明或登录入口。

迁移通过隔离 PostgreSQL 验证后才可应用开发 Supabase。未实际应用和完成真实集成测试时必须报告未联调，不把替身或本地 SQL 结果当成云端验收。摘要、Diamonds、支付和后台仍属后续任务。
