# ADR 0007：无登录页的首次引导

2026-11-01 用户提供 12 屏参考，指定从左到右、从上到下；本轮实现移动端 onboarding，不把登录页面插入该流程。FLIRTLY 暂作设计中的工作名称，图片为待替换开发素材。

顺序：启动 → 欢迎/成年确认与条款入口 → Role play → 角色类型 → 隐私介绍 → 相识 → 名字/代词 → 兴趣 → 偏好 → 目标 → 匹配介绍 → 可跳过的 Premium 介绍。使用全屏人物、底部暗色遮罩、红色主按钮、白色标题；不添加霓虹/虚假倒计时/虚假折扣。

Zustand + AsyncStorage 保存当前设备的版本化引导草稿与完成状态；恢复前不闪现错误页面。名字有长度校验，多选可取消且返回不丢失，成年确认必须显式选择。偏好只保存在当前设备，本轮不改变服务端数据模型，不称为完成云端身份或资料同步。

用户进一步确认整个 App 都不需要登录，直接使用；不加入登录页，也不在聊天前要求注册。无登录界面不等于绕过鉴权：引导完成后后台初始化真实 Supabase 匿名 Auth 会话，现有 API 继续验证其 token，不接受客户端任意 ID。当前只读项目设置确认 Anonymous Sign-Ins 关闭，且移动端缺公开 publishable key；由用户在平台开启并填写后才能真实验证，不擅自修改平台配置。会话在 iOS SecureStore 保存，web 测试使用 sessionStorage，不把凭证放在引导偏好存储。原 Apple 登录要求不再作为日常使用门槛；卸载/换设备与将来购买恢复仍需独立设计验收，不承诺匿名资料自动跨设备恢复。

最后一屏允许 No thanks 完成引导。RevenueCat 尚未接入，Subscribe 不发起扣款、不授予 Premium、不写虚假钱包余额；不在价格未配置前编造商品/试用价格。隐私、条款入口使用运营方配置的公开 HTTPS URL，缺失时明确提示暂时无法打开，不把占位文案冒充正式法律条款。

参考图中的裸露/露骨暗示文案不作为产品边界变更；按现有成年、非露骨互动 PRD 使用克制的交谈与角色照片文案。本轮不实现图片付费权益、聊天额度、订阅权益或流式对话。

验收：完整顺序、返回/多选/输入/成年门槛、重启恢复/完成跳过、可跳过 Premium、窄屏/键盘/安全区、屏幕阅读标签和减少动态效果；运行工程检查、Expo web 导出与浏览器移动视口交互。浏览器通过不等于 iPhone 真机验收。
