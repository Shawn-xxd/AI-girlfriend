# Onboarding 开发素材

onboarding-portraits.png 是本轮生成的 3 列 × 2 行、六位虚构成年人的人物联系表，用于用户给定 onboarding 参考的开发预览。Portrait 组件在渲染时选择对应区域，不修改原图。正式角色素材、运营审核与图片权限系统在后续阶段接入；该素材不代表已发布角色或已购买照片。

`startup-wordmark.png` 是原生启动屏本地字标（透明 PNG，1024×320），使用 Liberation Sans Bold 绘制 TEMPTA。背景色由 expo-splash-screen 插件配置为 #111112，不从网络下载。
